# Mentat Review Discipline

Every architectural decision and experiment must answer:

1. **What must be true for this to be true?**
2. **What assumptions created the question?**
3. **What plausible alternatives were excluded?**
4. **What evidence would change the conclusion?**
5. **What important information is missing?**

For incentive/selection questions also ask:

- Who benefits if this metric becomes the target?
- What happens if every worker optimizes it?
- Can the metric be gamed without creating real user value?
- Is the apparent “emergence” just hidden centralized routing?
- Would a simpler scheduler explain the same result?
